# الشهود · Al-Shuhud

أزمات البشر كما تعيشها الكائنات الأخرى.

النسخة المستقلة من «الشهود». تعمل من أي متصفح، وتُضاف إلى شاشة الهاتف كتطبيق، ولا تحتاج رصيد Claude.

## ما يعمل دون Claude
- النشرة الحية والمراسلون والرصد، مع كل المواد المحفوظة.
- الرصد يتحدث كل ساعة مجاناً من خلاصات وكالات بيئية وإخبارية (`scripts/feed.mjs` عبر GitHub Actions).
- كتابة المواد يدوياً، وإضافة الصور، والتصدير إلى بطاقات وإنفوجراف وفيديو.
- «عبر محادثة Claude»: نسخ الطلب ولصق الرد من أي محادثة.
- الكتابة الآلية اختيارياً بمفتاح Anthropic API خاص (رصيد منفصل عن اشتراك Claude).

## ما يضيفه Claude حين يتوفر الرصيد
- نشرة الصباح اليومية والرصد التحريري كل ساعتين، تُكتب في `data/pieces.json` و`data/monitor.json`.

## الملفات
- `index.html` يُبنى من مصدر الصفحة المشترك عبر `build.py`.
- `local.js` يحفظ ما تضيفه على جهازك (IndexedDB) ويدمجه مع ملفات `data/`.
- `data/pieces.json` المواد، `data/monitor.json` رصد Claude، `data/feed.json` الرصد الآلي.

ما تكتبه يدوياً يُحفظ في المتصفح الذي كتبته فيه. لنقله إلى جهاز آخر يلزم إضافته إلى `data/pieces.json`.
